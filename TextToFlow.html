Shapes are picked for you

  • Rounded: Start, End, Stop, Finish - also the first box, and any box with no arrow going out
  • Diamond: made by if, or a name ending in ?
  • Database (cylinder): name has DB, Database or SQL in it, e.g. Read DB
  • Hexagon: a loop - for each ...
  • Checklist: made by a todo line - turns green when every item is ticked
  • Red box: name has error, failed, failure, exception, invalid, denied, rejected, timeout or abort
  • Green box: name has success, succeeded, completed, done, OK, passed or resolved
  • Arrows: Yes = green, No = red
  • Slanted (teal): name starts with Read, Get, Send, Save, Print or Export
  • Rectangle: everything else. Right-click a box to pick a shape yourself.

Mouse

  • Drag a shape from the left bar onto the canvas (or click it)
  • Drag a box to move it. Auto layout tidies it all again.
  • Drag from a blue dot to another box to link them. Drop on empty space = new box.
  • Double-click a box to rename. Double-click empty space to add a step.
  • Click a box or arrow, then Delete. Right-click a box to add a note, put it in a lane or pick a shape.
  • Click a tick box in a checklist to tick it. Right-click a checklist > Add item.
  • Mouse wheel zooms. Drag empty space to move around.
  • 1 2 3 shows step numbers. Copy picture copies the diagram - paste it into Outlook, Teams or Word.

Keys
